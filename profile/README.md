## Engineering principles

- One repository per product, with a clear README and independent history.
- Secrets, local databases, dependencies, builds and backups remain outside Git.
- Type checks, tests and production builds are used where the project supports them.
- Responsive behavior, accessibility and visual hierarchy are treated as product requirements.
- Operational projects prioritize explicit workflows, auditability and maintainable architecture.
